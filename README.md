# FreeClay 0.1.7 — Blender 5.2 用スカルプト試作

「面数を管理する」操作を減らし、粘土を触る流れの中で余分な面をなぞって取り除くための拡張です。
Sculptris の Reduce に近い使い方を目標にしています。Sculptris のコード・アイコン・ブラシ素材は使っていません。

主な操作は **左右対称で Grab → Shift でスムーズ → 模様を彫る → R を押して一筆だけ Reduce → 元のブラシで続ける** です。
左右対称はオブジェクトのローカル X 面が基準です。

## インストールと最初の一筆

1. [FreeClay 0.1.7 ZIP](dist/freeclay-0.1.7.zip) をダウンロードします。Blender 5.2 の「編集 → プリファレンス → アドオン」のメニューから「ディスクからインストール」を選び、このZIPを指定します。
2. 3D ビューで N キーを押し、サイドバーの **FreeClay** を開きます。
3. **新しい粘土** を押します。既存モデルなら **粘土として開く（コピー）** を使います。
4. G でつかみ、ドラッグで形を作ります。Shift を押しながらなぞると、その一筆だけスムーズになります。
5. C で溝、D で盛り上げを彫れます。
6. **R を押す → 左ドラッグでなぞる → 離す** と、その一筆だけ余分な面を減らします。元のブラシに戻るので、そのまま形作りを続けられます。

ZIP は展開せずにインストールできます。ソースコードは `freeclay/`、公開用の検証結果は [docs/validation.md](docs/validation.md) にあります。
既存の Blender ウィンドウやユーザーの設定ファイルには自動インストールしていません。

## 0.1.7：対称面の縫い目を作りにくくする

**左右のブラシ範囲が直径の半分以上重なると、Grabは一体の範囲として扱います。** 判定は左右の中心間距離が半径以下の場合です。中央を挟む二つの円の間を埋めた範囲になり、プレビューも一つの輪郭に変わります。中央で左右の効き方を切り替えていた折れ目をなくし、強度1.0の追従は維持します。一筆の途中で方式が切り替わらないよう、Grabの判定は押し始めに固定します。

Reduceも大きく重なった範囲を一体として扱います。中央の隣接頂点を左右で共有しているだけでは削減を止めず、左右同時に縮約した後の接続を確認します。中央へ両側から縮約する場合も対称面の頂点を残し、中央の細かい帯を整理できます。残す頂点は移動せず、マスク・境界・形状誤差の保護は継続します。

すでに跡がある場合は「ならす」で表面を整えてから、中央をまたいで「軽くする」を試してください。実際に隆起・折り返しが残っている形状や左右の対応がない部分では、形状保護のため削減が止まる場合があります。自動溶接や既存の重なり面の修復ではありません。

## 0.1.6：長く引っ張るGrabの面を補う

従来のGrabは頂点移動だけだったため、長く引くと細長い三角形ができ、曲面を表現しきれなくなっていました。0.1.6は**引っ張る途中で伸びた辺だけを分割**し、曲がりを表現する頂点を補います。全体をリメッシュしたり、平滑化したりする処理ではありません。

**強度の最大1.0と直接追従は維持**しています。左右対称では分割順序も左右で揃え、マスクを引き継ぎます。増えた面は引き続きReduceで整理できます。元のカーソル位置へ戻す／Esc／Undoでは、この一筆で追加した面も戻ります。

長い一筆では計算量が増えます。任意の形への押し込みや、別の部位との衝突すべてを防ぐ機能ではありません。すでに破綻した形状を自動修復するものではないので、問題の一筆をUndoした状態から試してください。

## 0.1.5 の範囲・マスク・部品操作

**画面基準／モデル基準は全ブラシ共通の設定ひとつ**で切り替えます。初期値は画面基準です。

- **画面基準**：ズームしても円の見かけの大きさを保ちます。近づくほど細部を、遠ざかるほど広い範囲を扱えます。
- **モデル基準**：3D空間の大きさを保ちます。ズームすると円の見かけの大きさが変わります。
- **F**：モデルにカーソルを合わせ、左右に動かして範囲を調整します。左クリック／Enterで確定、Escで取消。ホイールでも微調整できます。
- サイドバーへカーソルを移して数値を変えても、最後に触った位置に範囲の円を残します。外側の円が範囲、内側は中心を見分ける補助線です。マスクや形状により実際に動く頂点は異なります。

Grab・回転・拡大縮小は同じ範囲と操作量を使います。他のブラシの大きさは個別に記憶しますが、範囲の基準は共通です。通常ブラシの数値はBlenderの**直径**、GrabとReduceの画面上の数値は**半径**です。

### マスクで触りたくない部分を守る

**Mでマスク**を選び、保護したい場所を塗ります。Ctrlを押しながらなぞると消し、Shiftで境界をぼかします。パネルに反転・全解除もあります。Grab・局所回転・局所拡大縮小では、マスクの濃さに応じて動きを抑えます。Reduceもマスクを保護します。

### 回転・拡大縮小とFIX

パネルまたはSpaceメニューの「回転」「拡大縮小」を選び、左右にドラッグします。

- **ブラシ範囲**：触った場所を中心に範囲内を変形。回転軸は視線方向、拡大縮小は触った点を中心とします。マスクと左右対称を使えます。
- **部品全体（FIX）**：Grabは移動、回転はワールドZ軸回転、拡大縮小は均等スケールです。ドラッグ中に **X／Y／Z** を押すとワールド軸を指定し、同じキーをもう一度押すと解除します。視線に沿う移動軸は左右ドラッグで動かします。
- FIXは頂点を変形せず部品全体の変換を変えます。範囲・マスク・左右対称は適用しません。チェックした他のClayも、編集中の部品の中心を基準に一緒に動きます。

### 部品を複製して組み立てる

1. 残したい場所にマスクを塗り、**取り出したい部分を未マスク**にします。
2. **Copy**で複製、または**Cut**で切り取ります。全頂点のマスク値が0.5未満の面が対象です。マスクがなければ部品全体が対象になります。
3. **Paste**で元の位置に独立したClayを作ります。自動的にその部品へフォーカスし、FIXに切り替わります。
4. Grab／回転／拡大縮小で配置します。Pasteを繰り返すと同じ部品を追加できます。
5. Clay一覧の**名前**で編集対象を切り替えます。左のチェックはFIXで一緒に動かす部品の指定です。「新規」で別の球も追加できます。

貼り付けた部品は独立したメッシュです。重ねても自動的には融合しません。部分Cutの切り口は開いたままで、自動で蓋は作りません。全体Cutした元部品は非表示となり一覧から外れます。Copy／Cut／PasteはUndo／Redoに対応し、クリップボードもblendファイルに保存されます。

更新前に作業を保存し、ZIPで更新後はBlenderを再起動してください。旧blendに保存されている操作量は維持されるため、強すぎる場合は**0.35**へ下げてください。

## 0.1.4 から継続する起動修正

新しいシーンで「新しい粘土」または「粘土として開く」を使ったとき、`NoneType ... use_symmetry_x` のエラーが出る問題を修正しました。Blenderがスカルプト設定を作成する前に読み取っていたため、スカルプトモードへ入ってから設定を取得する順序へ変更しています。
旧版で開始に失敗した粘土が選択されている場合も、開始用のボタンを表示します。旧版が途中で作成したオブジェクトは自動削除しません。更新後はBlenderを再起動してください。

## 表示機能（0.1.3から継続）

FreeClayパネルの「表示」から切り替えられます。

- **ソリッド＋ワイヤー**：陰影の付いた粘土に辺を重ねて表示します。もう一度押すとソリッドだけに戻ります。
- **頂点数・面数**：ビュー左上にBlender標準の統計を表示します。新しくFreeClayを開始するとオンになります。旧版の保存データでは、このボタンで有効にしてください。

Reduce・Grab・通常ブラシの操作中も、現在のメッシュに応じて数値が更新されます。細分化中は面数が「Triangles（三角形）」と表示されますが、FreeClayの粘土は三角形メッシュなので面数に相当します。Reduce／Grab中は一時的にObjectモードとなり、統計は選択物／シーン全体の形式になる場合があります。
「通常操作へ戻る」で、開始前の表示設定を復元します。切り替えは表示だけに作用し、メッシュの辺や面を増やしません。

## Grab と回転操作（0.1.2から継続）

対称面に頂点を押し付ける処理をやめ、ブラシの移動に合わせて変形を小刻みに積み重ねる方式に変更しました。中心線付近の頂点が同じ位置に潰れる問題と、長い移動で面が折り返す問題を修正しています。中心線に向かう横方向の移動は、左右が交差しないよう滑らかに圧縮します。中心線と平行な引っ張りはそのまま追従します。

回転操作は **右ドラッグ＝物体の中心、ホイール押し込みドラッグ＝触った位置** に変更しました。物体中心は現在の形の外接ボックス中心です。触った位置に面がない場合は現在の視点中心を使います。どちらも Shift を添えると平行移動です。

Grab を選ぶと、上部と FreeClay サイドバーで移動量と範囲を調整できます。

- **初期移動量 0.35**：カーソル60pxに対して、つかんだ頂点を21px動かします。スライダー・数値入力とも最大 **1.0** まで設定でき、1.0ではつかんだ頂点がカーソルに直接追従します（マスクと対称面の制約を除く）。
- **画面基準**の初期半径は100px。数値入力で最大4000pxまで広げられます。
- **モデル基準の範囲 1.0**：開始時モデルの直径と同じ大きさ。**3.0 / 5.0** で初期球の3倍・5倍、最大 **20.0** まで設定できます。
- 筆圧による強さの低下は初期状態では無効です。必要なら「Grabに筆圧を使う」をオンにします。
- 大きな範囲が左右を覆っても、対称な引っ張りが互いを打ち消さない専用処理を使います。
- 対称面上では横方向を固定し、面に沿う方向には動きます。マスクされた箇所の拘束も優先します。

GrabとReduceの大きさは独立して記憶し、画面／モデルの基準だけを共通設定にしています。
強さ1.0・範囲5倍と20倍・左右対称で、カーソル60pxに対してつかんだ頂点60pxの移動をGUI試験で確認しました。
一筆のUndo/RedoとEsc取消も確認しています。物理ペンタブレットの筆圧はまだ未検証です。
更新前に作業を保存し、ZIPで更新後、Gを押し直してください。古いコードが残る場合はBlenderを再起動してください。

## 手元の操作

| 操作 | 動作 |
|---|---|
| G / D / S / C / M | つかむ / 盛る / ならす / 溝 / マスク |
| F → 左右に動かす → 左クリック | 円を見ながら範囲を調整 |
| Shift ＋ 左ドラッグ | 通常ブラシで一時的にスムーズ |
| Ctrl ＋ 左ドラッグ | 通常ブラシの反転 |
| Q | Reduce を選択し、続けてなぞる |
| R を押して左ドラッグ | 現在のブラシから、一筆だけ Reduce |
| Reduce 中のホイール | Reduce の大きさを変更 |
| Esc | Grab / Reduce / 回転 / 拡大縮小の進行中の一筆を取り消す |
| Ctrl Z / Ctrl Shift Z | Undo / Redo |
| 右ドラッグ | 物体の中心で視点を回す |
| ホイール押し込みドラッグ | 触った位置を中心に視点を回す |
| Shift ＋ 右／ホイール押し込みドラッグ | 視点を平行移動 |
| ホイール | 通常時はズーム |
| Space | 手元にブラシメニューを開く |

Reduce の「効き具合」は一度になくす辺の数と到達する粗さ、「形を守る」は形状誤差の許容度です。
まず初期値のまま同じところを何度かなぞってください。止めているだけでは減り続けません。
頂点数・面数の表示はパネルからオン／オフできます。Reduce の大きさ・効き具合は通常ブラシのサイズ・強さとは別です。

左右対称 Reduce は、対応する左右の辺を一組として減らします。新しい粘土は最初から対応した形になっています。
外部モデルで見た目が対称でも頂点配置が違う場合、対称 Reduce が効きにくいことがあります。
必要な場合だけ **左右の形を揃える（−X → ＋X）** を使ってください。これは −X 側の形を ＋X 側へ写す形状編集です。
非対称の形を残したい場合は、左右対称をオフにします。

## 形を保つための処理

- ブラシ範囲と連結した表面だけを対象に、形への影響が小さい辺から縮約します。
- 残す頂点を移動しません。Reduce 自体に平滑化や体積を縮める処理は混ぜていません。
- 元の面からの距離、面の向き、極端につぶれた三角形、接続関係を確認してから減らします。
- 境界、急な稜線、マスクされた頂点、非表示面、明示した UV シーム、Face Set の境界を保護します。
- 薄い別の表面に削減が飛び移らないよう、最初に触った三角形の対応を追跡します。
- 対称時は、両側とも条件を満たす組だけを削減します。中央の共有頂点を含む組は、左右同時の接続も検査してから削減します。

形の誤差チェックは有限のサンプルによるもので、任意のモデルで誤差上限や体積の完全保存を保証するものではありません。
一筆ごとの元形状を基準にするため、長時間繰り返した累積誤差にも限界があります。

## 自動細分化とデータ

初期状態では、盛る・溝・スムーズの細分化に Blender の Dyntopo を使います。Grab / Reduce / マスク / 部品操作のあと、次の通常ブラシの一筆で自動復帰します。
内部では Grab / Reduce / 局所変形中は通常メッシュとして編集し、一筆の終了時に Sculpt モードへ戻します。Grabは伸びた部分の面を必要に応じて補い、回転・拡大縮小は頂点移動だけを行います。
これは Undo を正常に記録するための切り替えです。

既存モデルは、表示されている形を別のメッシュへコピーしてから作業します。元モデルは非表示にし、削除しません。
コピーはモディファイアの結果を取り込み、三角形化します。元のリグ・シェイプキーを編集するための機能ではありません。
Dyntopo はコピー側の UV などの属性に影響するため、テクスチャ済み完成モデルの属性保持は対象外です。
**通常操作へ戻る** で専用キー割り当てを外し、元モデルの表示と保存していたビュー設定を戻します。

## 確認した範囲と残る課題

Windows / Blender **5.2.2 LTS、d13f752e3b9c** で確認しています。
形状・マスク・境界・薄い二重表面・対称削減の試験と、専用の非アクティブデスクトップ上の Blender に対する入力試験を行っています。
結果の要約は [検証記録](docs/validation.md) を参照してください。個人環境のログ・画面・作業用モデルは同梱していません。

これは Sculptris と同じ触感を達成した完成版ではありません。実際の手での速度感、ペンタブレットの筆圧・遅延、非常に高密度なモデルは別途調整が必要です。
Grabは既存の重なり面を修復する処理ではなく、任意の形状や極端なマスク境界での自己交差すべてを防ぐ機能でもありません。
右ドラッグの視点操作と少数のブラシに絞った画面を実装していますが、Sculptris の背景ドラッグや全ショートカットを完全再現したものではありません。
中心面付近や細い特徴、対応する左右頂点がない部分では、形状保護を優先して削減が止まる場合があります。

## 開発・再検証

最初に作業用の `verification/` ディレクトリを作成してください。`tools/test_freeclay.py` を Blender の `--background --factory-startup --disable-autoexec --python-exit-code 17 --python` で実行します。
GUI 検証は `tools/test_gui.py` と `tools/run-gui-test.cjs`。WindowsBackgroundUse の専用ワーカーを使い、Blender 自身の `Window.event_simulate` で入力します。
GUIランナーには別途 [WindowsBackgroundUse](https://github.com/urdcat/WindowsBackgroundUse) が必要です。`FREECLAY_DESKTOP_CLIENT` に `desktop-client.cjs`、`FREECLAY_DESKTOP_WORKER` にビルド済み `desktop-worker.exe`、`BLENDER_EXE` にBlender実行ファイルのパスを指定できます。ワーカーはこのリポジトリに同梱していません。
例: `node tools/run-gui-test.cjs grab-check test_grab.py`。回転操作は `test_navigation.py`、中心線の形状検証はBlenderのバックグラウンド実行で `test_centerline.py` を使います。結果はローカルの `verification/` に生成され、Git管理対象外です。
範囲とマスクは `test_interaction.py`、部品変形は `test_parts_gui.py`、コピー操作のUndoは `test_clipboard_gui.py` でGUI検証します。部品の形状・マスク・フォーカスはバックグラウンド実行の `test_parts.py` を使います。
メインデスクトップへ入力する試験ではありません。ワーカーが権限エラーで停止した場合、前面操作へ切り替えず、環境の正式な権限審査を使います。
`tools/build.ps1` は外部パッケージを取得せず、配布 ZIP を作成して Blender の検証コマンドに通します。

Python は Blender のアドオン API・BMesh・スカルプト検証に必要な範囲だけで使用します。
依存は既存の Blender 同梱 `bpy` / `bmesh` / `mathutils` / `gpu` / `numpy` と標準ライブラリだけです。NumPyはGrabの小刻みな変形をまとめて計算し、待ち時間を抑えるために使います。pip・追加 Python・外部 Python パッケージは使用しません。
梱包・ファイル処理・Windows ワーカー管理は PowerShell と Node.js 標準機能を使います。
