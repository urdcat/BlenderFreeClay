# FreeClay 検証記録

## 0.1.4：未初期化シーンからの開始

2026-11-26、Blender 5.2.2 LTSでユーザー報告と同じ `AttributeError: 'NoneType' object has no attribute 'use_symmetry_x'` を再現しました。従来のfactory-startupだけでは既にスカルプト設定が存在するため、検証中に新しいシーンを作り、`scene.tool_settings.sculpt is None` を明示的に確認しています。

スカルプトモードに入った後で設定を取得する順序に変更しました。`tools/test_startup.py` では未初期化状態からの新規球・既存メッシュのコピー、ブラシと表示切り替え、通常モードへの復帰、既存設定を持つシーンでの再開始と設定復元を確認しました。既存の形状処理・表示設定復元の回帰試験も成功しています。

GUI通し試験でも未初期化シーンからの開始、ワイヤーと数値表示、Grab／Smooth／Crease／Reduce、Undo／Redo／取消、保存に成功しました。旧版が途中で作成したオブジェクトの自動削除は行いません。

## 0.1.3：表示機能

2026-11-26、同じBlender 5.2.2 LTSで次を確認しました。

- ソリッドにワイヤーを重ね、表示オン／オフを切り替えられること。線の不透明度は0.35、表示対象の辺の閾値は1.0です。
- ビュー左上の標準統計がReduceのドラッグ中に更新され、表示された面数が実際のメッシュと一致すること。
- Dyntopoによる細分化のドラッグ中にも頂点数・三角形数が増加すること。描画画面も確認しました。
- 表示の切り替え、旧版保存データの表示設定補完、「通常操作へ戻る」で開始前のシェーディング・オーバーレイ設定が復元されること。
- 既存のGrab／Smooth／Crease／Reduce、Undo／Redo／取消のGUI回帰試験。

統計とワイヤーにはBlender標準機能を使用し、独自の常駐タイマーやポリゴン走査は追加していません。

## 0.1.2：Grabと回転操作

2026-11-26、Windows / Blender 5.2.2 LTS（d13f752e3b9c）で検証しました。
これは試作版の確認範囲を記録したもので、Sculptrisと同一の触感や任意のモデルでの結果を保証するものではありません。

## 結果

| 対象 | 確認した結果 |
|---|---|
| Reduce | 形状誤差、マスク、境界、薄い二重表面、対称な削減、多様体を検証 |
| Grab | 強さ1でカーソル60pxに対し対象頂点60px、強さ0.35で21px |
| 大きなGrab | 初期直径の5倍・20倍、左右対称で追従性を確認 |
| 中心線付近のGrab | 平面と球の10ケースで中央への潰れ・退化面・非隣接三角形の交差なし。平面の反転もなし |
| 中心線GrabのGUI入力 | 直進・内向き・外向きの3ケースで潰れ・退化・交差なし |
| Undo／Redo／Esc | GrabとReduceで復元を確認 |
| 回転 | 右ドラッグで物体中心、中央ドラッグで触った位置が画面上で固定されることを確認 |
| 平行移動・取消 | 両ボタンのShift移動、Esc取消、ボタン解放後の終了、メッシュ不変を確認 |
| 操作の連続 | Draw → Grab → Shift Smooth → Crease → Reduce → 保存を確認 |
| 再読込 | 別プロセスで20,676面の保存データを再読込し、多様体と対称設定を確認 |
| 配布ZIP | Blender拡張の検証コマンド成功。収録5ファイルとソースのSHA-256一致 |

旧0.1.1の同一形状試験では、球の中央付近の内向き移動で120頂点が対称面に潰れ、非隣接三角形33組が交差しました。0.1.2では、対称面への座標の切り詰めをやめ、移動するブラシの変形場を小刻みに積分する方式に変更しています。

平面上の重なりはBVHの交差検出だけでは評価できないため、平面では三角形の向きも検査しています。マスク境界を含むすべての形状での自己交差防止、既存の重なり面の修復、物理ペンの触感・入力遅延は検証対象外です。

## 再検証用スクリプト

- `tools/test_freeclay.py`: ReduceとGrabの基礎検証、セッション復元。
- `tools/test_centerline.py`: 中央付近の形状検証。`--previous` は別途用意した旧0.1.1 ZIPとの比較用で、通常の実行には不要です。
- `tools/test_grab.py`: GUI上の追従量、中央付近の形状、Undo／Redo／Esc。
- `tools/test_navigation.py`: GUI上の回転中心、平行移動、取消。
- `tools/test_gui.py`: スカルプト操作の連続、保存。
- `tools/check_demo.py`: 検証で保存したblendファイルの再読込。

GUI試験には、別途用意したWindowsBackgroundUseの専用非アクティブデスクトップとBlender自身の `Window.event_simulate` を使用しました。これは一般的な前面マウス操作や物理ペン入力の試験ではありません。

個人環境の設定、画面、プロセス情報、実行ログ、生成したモデルは公開リポジトリに含めていません。再検証時の結果はローカルの `verification/` に出力されます。
