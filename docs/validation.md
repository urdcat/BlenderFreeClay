# FreeClay 検証記録

## 0.1.7：重なる対称ブラシの一体化と中央Reduce

2026-11-27、Blender 5.2.2 LTS。比較対象は同梱の0.1.6 ZIPです。ユーザー画像のモデル自体は取得していないため、対称面の折れ目と細い三角形の密集帯を専用メッシュで再現しています。

- Grabの左右の中心間距離が半径以下、すなわち直径の半分以上重なるとき、二つの中心を結ぶ一体の範囲を使います。中央の効き具合に折れ目がなく、強さも二重になりません。押し始めに方式を固定します。
- 半径1、中心X=0.2、移動Z=0.4の平面試験では、旧版の中央高さ0.36839に対し掴んだ位置は0.4で、中央の片側勾配は0.29346でした。修正版は両方0.4、中央の片側勾配0です。
- 平らな面の中央密集帯に同じReduce操作を60回適用しました。中央の評価範囲は105頂点から、旧版では34頂点、新版では2頂点となりました。残した頂点の位置は不変、退化面・非多様体辺・ミラー誤差は0です。
- 中央の共有頂点への左右同時縮約では、重複面と縮約後の頂点周囲の接続を追加検査します。中央を跨いで左右を直接潰す操作は許可せず、マスク・隠し面・境界・稜線・表面誤差の既存保護も継続します。
- 閾値の両側とワールド空間の拡大率、共有する中央領域のマスク保護を確認しました。Reduceの形状・薄い裏面・境界・対称性、中心線10条件、長いGrab7条件も回帰試験に成功しました。
- 専用の非アクティブBlenderで、一体化したプレビュー、Grab → Blender標準のSmooth → 中央を跨ぐReduceを実行しました。最終試験ではReduceの前後で評価帯の頂点が180から117へ減り、退化面・非隣接面の交差なし。Undo／Redoで形状と面の接続を復元しています。別プロセスで保存した20,308面の多様体と対称設定も確認しました。

追加検証スクリプトは `tools/test_seam.py` と `tools/test_seam_gui.py`。`test_seam.py -- --previous` で旧0.1.6を比較します。メッシュの検証はBlender内蔵API・BMeshを必要とし、外部Pythonパッケージは追加していません。

一体化した範囲は二円の間を埋める形です。プレビューも一つの輪郭になります。単に中央の左右を溶接したり、保存済みモデルを対称化して上書きしたりする処理ではありません。既存の強い隆起・折り返しや左右に対応頂点がない場所では、保護条件により削減できないことがあります。物理入力の触感やユーザーモデルでの跡の完全除去は未確認です。

## 0.1.6：長いGrabで伸びる三角形の補完

2026-11-26、Blender 5.2.2 LTS。0.1.5 ZIPのGrabと同じ初期球・移動量で比較しました。球の直径3に対し2〜4の長い移動、中央・中央付近・対称面へ向かう移動・外向き・非対称・マスクを含む7条件を検証しています。

- 旧版の6条件では最大辺長が1.54〜2.91となり、長い三角形に曲面の表現を任せていました。これらの単純な球では旧版でも交差は検出されていません。ユーザー画像のモデルそのものを再現したという意味ではありません。
- 新版は変形を進めながら伸びた辺を局所分割します。7条件で最大辺長は約0.17、退化面・非隣接三角形の交差0、多様体を維持しました。対称条件の最大ミラー誤差は8.84e-9未満です。
- マスクされた元頂点の座標とマスク値を保持し、再度長く引いた形状でも退化・交差なし。一筆の開始位置に戻すと追加頂点を含めて元メッシュへ戻ります。
- GUIでは強度1.0で240pxのドラッグに対し240.00003px追従。21,224面から25,434面へ補完し、Undo／Redoと補完後のEsc取消を確認しました。別プロセスで保存データの25,434面・多様体・対称設定を確認しています。
- 通常Grab、中心線10条件、Reduce基礎検証、Draw／Grab／Smooth／Crease／Reduceの連続操作も回帰検証しました。

実装では分割を三角形ごとに行い、左右の分割順序も対応させます。一筆の開始形状から再計算し、同じ終点を再評価する入力は省きます。今回の5,480面の試験で長い一筆の1回の評価は約0.1〜0.4秒でした。これは描画遅延や物理入力の応答時間ではなく、すべての高密度モデルに快適な応答を保証するものでもありません。

既存の重なり面の修復、任意形状への押し込みによる衝突回避、極端な距離・非常に高密度なモデルは保証対象外です。追加頂点数には一筆約50,000頂点の計算上限があり、上限を超える変形では面の補完が追いつかない場合があります。増えた面をReduceで整理する流れは維持しています。

追加検証は `tools/test_long_grab.py`。`--previous` で同梱の旧0.1.5 ZIPを比較対象にします。Pythonの用途はBlender API・BMesh・同梱NumPyによるメッシュ検証に限定し、外部パッケージは追加していません。

## 0.1.5：共通範囲・マスク・Clay部品

| マスク | 前面への塗り、Ctrl消去、Shiftぼかし、反転・全解除。マスクだけの操作で形状不変。148の完全保護頂点に対するGrabの最大移動8.95e-8未満 |

範囲円は操作半径の表示です。すべての頂点が同じだけ動くことを示すものではありません。マスク・表面方向・左右対称による制約は別に働きます。物理ペンの入力・操作感、高密度モデルの応答、任意形状での自己交差防止は未検証です。局所回転・拡大縮小の対称処理についても、Grabの中心線試験結果をそのまま適用するものではありません。

部分Cutは開いた切り口を残し、Pasteは独立した部品を作ります。自動キャップや部品間のBoolean融合は実装していません。FIXではマスク・左右対称を無視し、オブジェクトのワールド変換を編集します。

追加スクリプトは `tools/test_interaction.py`、`tools/test_parts.py`、`tools/test_parts_gui.py`、`tools/test_clipboard_gui.py`。Pythonの追加はBlender内のAPI・メッシュ・GUIイベント検証に限定しています。外部Python／pip依存は追加していません。Python使用縮減の基準点は更新せず、差分を要確認として記録します。
